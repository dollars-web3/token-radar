How the ranking works

Implied value is calibrated on the protocols that already trade. For each category, the model takes the median market-cap / TVL ratio of that category's tokened protocols and applies it to the pre-token protocols in the same category, then adjusts for 7-day TVL momentum and for how long the protocol has run without a token: implied = TVL × peer multiple × growth factor × maturity factor. Categories with too few tokened peers fall back to the global median (—). Before any ranking, a structural screen sets aside — entries that record no token but are wrapped, staked or bridged products of one that already trades — or an exchange's reserve tracker — using the same signals the snapshot's own watchlist uses: their value already trades under another name, so they have no launch of their own. No name is hand-picked or hand-weighted: feed the model a new snapshot and the board re-derives itself. A protocol here records no token in the snapshot — that is a statement about the record, not a promise of a launch.
