# Token Launch Radar

Every protocol that records no token yet, ranked by what its launch could be worth — with a plan to farm each one.

A peer-calibrated model: each category's implied values come from the median market-cap/TVL ratio of that
category's already-tokened protocols in the sealed DefiLlama snapshot, adjusted for 7-day TVL momentum and
for how long the protocol has run without a token. A structural screen first sets aside wrapped, staked and
bridged products of tokens that already trade (and exchange reserve trackers), so the board ranks only
protocols with a launch of their own still to come. The dashboard is a static page — sortable, filterable,
with a detail view and farm plan for every protocol — that recomputes every value it shows from the same
inputs, so the page and board.json are visibly the same arithmetic.
